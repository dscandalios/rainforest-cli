# Assets

Drop the following PNGs here before building for production:

- `icon.png` — 1024×1024 app icon
- `adaptive-icon.png` — 1024×1024 Android adaptive foreground (transparent background)
- `splash.png` — 1284×2778 splash screen image
- `favicon.png` — 48×48 web favicon

For local Expo Go runs, the build will use Expo defaults if these are missing — the `app.json` references are aspirational.
